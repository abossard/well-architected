About this project

Extracted from the Azure Well-Architected Framework using LightRAG and Claude Opus 4.6 knowledge-graph analysis.

  1. Ingested 13 mission-critical + 21 WAF pillar docs into LightRAG.
  2. Extracted entities via Claude Opus 4.6 through copilot-api proxy.
  3. Generated embeddings with text-embedding-3-small (1536 dims).
  4. Ranked mental models by graph centrality + bridge score.
  5. Classified 4,099 entities into 9 categories via LLM.
  6. Generated cards with mantras, failure modes, and tradeoffs.
Run locally

Requires a GitHub Copilot subscription for the proxy.

# Start copilot-api proxy
npx copilot-api start --port 11435

# Install dependencies
cd kg-explorer && python3 -m venv .venv && source .venv/bin/activate
pip install lightrag-hku

# Ingest, mine, query
python3 ingest_lightrag.py
python3 mine_mental_models.py --top 25
python3 query_lightrag.py "What is blast radius thinking?"
