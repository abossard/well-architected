How it was built

  1. 13 mission-critical + 21 WAF pillar docs ingested into LightRAG
  2. Entity extraction via Claude Opus 4.6 through copilot-api proxy
  3. Embeddings via text-embedding-3-small (1536 dims)
  4. Graph centrality + bridge score analysis to rank mental models
  5. LLM classification of 880 entities into 9 categories
  6. Mental model card generation with mantras, failure modes, tradeoffs

Run locally

# Start copilot-api proxy (needs GitHub Copilot subscription)
npx copilot-api start --port 11435

# Install dependencies
cd kg-explorer && python3 -m venv .venv && source .venv/bin/activate
pip install lightrag-hku

# Ingest docs
python3 ingest_lightrag.py

# Mine mental models
python3 mine_mental_models.py --top 25

# Query
python3 query_lightrag.py "What is blast radius thinking?"
